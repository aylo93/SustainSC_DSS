# MCDA56 runtime evidence subset

These files are copied without modification from
`SustainSCM_Romanian_56_Anchor_30KPI_MCDA_Package.zip`. They are a compact,
read-only runtime subset of the completed 56-anchor, 30-KPI experiment.

The ASCA interface retrieves these scientific outputs; it does not rerun WSM,
TOPSIS, KPI completion, normalization, optimization, simulation or training.
The raw and normalized 1,680-observation tables remain in the reproducibility
package and are intentionally not duplicated here.

Runtime files:

- `mcda_neutral_48.csv`
- `dimension_indices_56.csv`
- `strategy_robustness_summary.csv`
- `archetype_winners.csv`
- `mcda_all_weight_profiles.csv`
- `bounded_random_weight_winner_frequency.csv`
- `completion_sensitivity.csv`
- `summary.json`
